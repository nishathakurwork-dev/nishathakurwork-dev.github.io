# Nisha Thakur — Portfolio

Personal portfolio site for Nisha Thakur, Full Stack Developer
(WordPress, Shopify, BigCommerce, PHP, Laravel).

Published with GitHub Pages.

## About this repo

This is a static export of the site, which is authored as a WordPress
child theme (`twentytwentyfive-child`). The HTML here is generated —
edit the theme and re-export rather than hand-editing `index.html`.

```
index.html     the whole site (single page)
wp-content/    theme CSS/JS, fonts, images, resume PDF
.nojekyll      serve files as-is, no Jekyll processing
```

## Contact form

GitHub Pages serves static files only, so the WordPress mail handler is
not available. The form opens the visitor's mail client with the fields
pre-filled (`mailto:`). To take submissions server-side instead, point
the form at a form service (Formspree, Netlify Forms, etc.).
